Promoter account

Become a promoter to upload products, manage listings and access developer tools.

Your promoter account is active. You can have up to 5 live listings at a time. Each listing stays live for 72 hours unless bumped.

Upload a product

Maximum 4 live listings. Listings expire after 3 days. Product images are optional; you can use direct image links or upload an image while shared upload slots are available.

Developer

Create an API key for your own bots or integrations. Keep the key private. You can revoke it at any time.

Bot upload API

Send a POST request to https://shopperssuggestions.online/api/integrations/products with an Authorization header: Bearer YOUR_API_KEY, a JSON content type, and a JSON body containing title, description, category, affiliate_url, and optional image1_url through image5_url. The same 4-live-listing limit applies to bot uploads.
